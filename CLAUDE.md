# CLAUDE

Follow [AGENTS.md](AGENTS.md), then read [the founder brief](docs/AGENT_SYNC.md)
before product, roadmap, generation, or quality work.

The first milestone is a complete internal agency production tool that delivers
the first ready DOCX. Managers enter requirements, review, run Compilatio and
deliver; the system supplies sources and text. Tanya owns operational acceptance.
Existing tools retain CRM, payments and general client communication.

Current acceptance requires content/source quality, similarity ≤10% AND AI ≤10%
in Compilatio on the exact final file, and no human content rewrite.
Uploaded PDFs and methodology are optional. Missing evidence is not a pass.

Priority since 2026-09-09: a working platform first. Generation must complete
to DOCX for supported orders; quality checks inside generation are advisory,
strictness lives at release. The 10/10 bar stays the goal, not the current
gate. Reviewers judge direction before patch correctness. See the
`founder-priority-2026-09-09` block in the founder brief.

Use [the roadmap](THESICA-PLAN.md) and [execution queue](docs/PRE-RUN-001-TASKS.md).
Customer sales, self-serve checkout and feedback-driven revisions are deferred.
Respect authorization already given; a documentation rewrite is not a deployment
or paid-run authorization.

Read [DESIGN.md](DESIGN.md) before visual work. Preserve Scholarly Press:
warm paper, academic green, Literata, Source Sans 3 and JetBrains Mono.
Do not replace the visual system as a side effect of workflow changes.

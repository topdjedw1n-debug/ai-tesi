# Thesica

Thesica — внутрішня платформа виробництва академічних робіт для агенції.
Поточна ціль: менеджер самостійно проводить замовлення від вимог до
першої готової та перевіреної роботи у DOCX. Джерела й текст готує система.

Перший набір: італійські теоретичні/оглядові роботи, спочатку 10–20,
потім 40–50 сторінок. Готовність потребує якості змісту й джерел,
Compilatio ≤10% similarity та ≤10% AI на тому самому файлі й відсутності
переписування змісту людиною.

Агенція — постійний користувач. Її чинні інструменти ведуть клієнтів,
оплати та комунікацію. Доопрацювання за зауваженнями й окремий
клієнтський продукт відкладені.

## Стан

Є ядро генерації, автоматичних джерел, перевірок, відновлення,
інтерфейс менеджера та прив'язка видачі до файла. Повний внутрішній
продукт ще не прийнятий: потрібні реальні PASS та самостійний цикл Тані.
Поточний перевірений стан зафіксований у брифі; старі числа тестів і
деплоїв не є поточним статусом.

## Архітектура

Next.js web → FastAPI API → PostgreSQL.
Фонові задачі генерації зберігаються в базі; Redis використовується
сервісами, MinIO зберігає файли, зовнішні AI та академічні провайдери
забезпечують генерацію й пошук.

Ключові поверхні: менеджерська робота з документом, виробничий кейс,
докази якості та дозволена видача. Наявність старих клієнтських,
платіжних або редакторських екранів не означає їх готовності чи пріоритету.

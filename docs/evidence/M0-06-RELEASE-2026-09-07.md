## Межі доказу й наступний запуск

Підготовчі 1122 API / 192 web тести та незалежне рев'ю залишаються доказами
того самого коду. GitHub API повертає 0 запусків CI для цієї гілки; workflow
підписаний на main/develop/production. Відомий mypy: 354 помилки, 0 нових
відносно бази. Повний CI не оголошується зеленим.

Початковий серверний запуск тестів не підключив кореневий pytest.ini;
59 перевірок впали на об'єктах coroutine. Після передачі чинного
`asyncio_mode=auto` усі 63 пройшли без зміни продуктового коду. Помилково
створений порожній каталог від тестового mount видалено. Перша діагностична
перевірка також очікувала відсутнє поле is_admin у /auth/me; це виправлено
в сценарії перевірки, а роль перевірено в базі та через заборонений endpoint.

Код, робоча папка та вже підготовлені архівні/стратегічні зміни збережені.
Коміти робилися в окремому checkout; початковий Git index не змінювався.
У реліз не включено сторонній незавершений перегляд документації. Поточні
локальні бриф, план і черга оновлені точково; у GitHub опубліковано окремі
самодостатні релізні докази й запис наступного запуску.

READY / PENDING REAL RUN DATA. Таня входить через звичайний парольний
екран, звіряє умови наявної роботи та сама натискає «Підтвердити і запустити».
Її дозвіл на платні запуски вже надано фаундером; нового дозволу від нього

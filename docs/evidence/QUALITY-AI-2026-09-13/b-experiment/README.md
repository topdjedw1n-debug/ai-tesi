## 1. Умови

- Вхід для всіх чотирьох файлів — один запис роботи B (document14/job17, право, tesi magistrale, 30 сторінок, 24 розділи), SHA-256 запису `a50fdbfb913cfd32…`. Бриф, вимоги, пакет джерел, уривки, план S3, обсяг і бюджети — заморожені з запису; S1–S3 і всі їхні зовнішні входи взяті зі стрічки.
- Модель для S4–S6 — `claude-opus-4-8` (як у записі), параметри запиту незмінні (лише `model`, `max_tokens`, `messages`; sampling не чіпався). Усі 24 розділи написані наживо послідовно, кожен наступний бачив підсумки свого файла.
- `V0a`, `V0b` — виробнича інструкція S4 (SHA `cbc764f5…`); `V1a`, `V1b` — [варіант v1](../s4-lab/s4-instruction-variant-v1.txt) (SHA підставленого тексту `5377e13f…`). По два незалежні файли на варіант.
- Стеля `--cost-cap-usd 3` на файл; мережа — лише провайдер моделі та сервіси перевірки посилань; жодних змін коду, POLICY, сервера чи бази. V0a запущено окремо першим, решта три — паралельно після його завершення.

## 4. Сліпа оцінка Q і Compilatio — що далі

- [blind/](blind/) містить ті самі чотири DOCX під іменами `B-blind-1..4.docx` у випадковому порядку; відповідність — у `blind/KEY-do-not-share-with-evaluators.json`. Оцінювачам передавати лише сліпі копії, ключ — ні. Порядок за планом: спершу сліпа оцінка Q за рубрикою M1-Q02 (суддя + вибіркове читання редактором, без переписування), потім Compilatio на точних файлах (ідентичні байти в `docx/` і `blind/`, SHA вище).
- Compilatio: чотири перевірки — мінімум для першого сигналу; біля порога 10% — повторне сканування того самого файла. Рішення після результатів — за QUALITY-AI-ROUND1 §4.

- Варіант прибрав формулу «la letteratura disponibile non consente di…», але **не прибрав мета-коментар про межі уривків**: у V1a/V1b його ще більше, у формі «Gli estratti disponibili documentano…, ma non riportano…» (у V0a — «gli excerpt richiamati…», у V0b — «Va tuttavia rilevato che gli estratti disponibili non riportano…»). Це саме ризик правки 3, який називала Astra (технічний мета-коментар замість академічного викладу); чи вважати це вадою — питання для сліпої оцінки Q, а вплив на AI-показник — для Compilatio.
- Файли варіанта довші на 5–8 %, у V1b два розділи вийшли за верхню межу обсягу (штатне попередження, не зупинка).
- Довжина речень у всіх чотирьох майже однакова; механічного чергування ніхто не вимагав і не спостерігається.
- Два файли однієї інструкції помітно різняться між собою (V0a проти V0b за формулами обмежень) — це міра розкиду між незалежними генераціями, яку варто пам'ятати при читанні різниці між варіантами.

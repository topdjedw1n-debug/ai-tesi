# Консультація №9 (17.09.2026, після скану психології 6 / 20): напрямок перед кодом

**Підстава:** четвертий файл на замороженому писарі (психологія, магістерська, doc26) дав similarity 6 %, **AI 20 %** — перший вище рівня «продовжувати серію» (15 %). Фаундер: «Так, роби все покроково» — (1) калібрування якорів за $0, (2) копії з репозиторіїв за $0, (3) консультація перед будь-якою зміною замороженої рамки чи правил плану, (4) без платних прогонів до рішення. Запит з фактами, результатами кроків 1–2, варіантами A–D і моєю позицією (позначеною окремо): [request-round1.md](request-round1.md). Astra — Codex `gpt-6-astra`, лише читання; Grok — `grok-4.6` у plan-режимі; обидва читали докази й код. Відповіді: [astra-round1.md](astra-round1.md), [grok-round1.md](grok-round1.md). Один раунд: розбіжності передано фаундеру нижче, не «дожимались» повторним запитом.

## Де зійшлися (обоє)

- **Напрямок:** найпотрібніша зміна — **A, копії того самого запису**, насамперед пошук адрес за DOI для записів Crossref (6 з 8 здобутків психології). Це прямо відповідає розділам 49–63 % AI, де профільні статті (Valkenburg, Self-comparison with influencers) лишилися анотаціями.
- **Моє прочитання приймають частково:** «сторінки саме про питання розділу захищають» — найкраще пояснення на цьому файлі, але гіпотеза (розділи на анотаціях — 0 %); «магістерські мета-частини як клас» — не доведено (вступ PSY 0 %, висновки E2/BIO 0 %); «психологічна проза ближча до детектора» — неперевірене пояснення з одного файла, дисципліну як причину не приймати.
- **Ворота документа:** один фіксований лексичний поріг на всі дисципліни підбирати далі не варто (калібрування це показало); суд моделі обґрунтований, але **не в моєму вигляді** й лише після дешевої перевірки на записаних документах.
- **Чого не робити:** писар, модель, правила плану й рамки без нового речення; браузер/TLS проти 403; повтор того самого брифу платно на поточному сервері; зниження планки 10/10; зупинки генерації через попередження.
- **Similarity** може трохи зрости від ближчого переказу справжніх сторінок — бюджет цитат не чіпати, оцінювати одним сканом нового точного файла.
- **Обидва детерміновані залишки** (спільні слова без слів теми; власний термін вузла у вікні — не для рамкових розділів) — робити, але вони не заміняють суд моделі.

## Що зроблено після консультації ($0, локально, коміт 2 плану матеріалу)

1. **Копії (A):** `full_text_sources.open_access_urls` — усі відкриті адреси запису (репозиторні PDF першими, потім журнальні, лендинги лише без PDF), `open_access_metadata` зберігає список, S2 переносить його через злиття дублікатів і верифікацію; `open_access_locations(doi)` — один записаний виклик OpenAlex `works/doi:` (`executor_locations`) для відібраного запису без адреси; `attach_full_text` пробує адреси по черзі до першого текстового шару, ≤ 3 на запис, ≤ 60 на роботу, кожна спроба — записана залежність `executor_full_text`, у зведенні `tries`. Тести: порядок адрес; стоп після першого успіху; Crossref без адреси отримує один запит; стеля на запис і на роботу; тести виконавця не ходять у мережу.
2. **Рамка з комою (C за Astra):** `FRAME_TITLES` приймає кому й тире після рамкового слова.
3. **Спільні слова без слів теми (залишок a):** `section_fit`/`about_section` отримують тему; у `section_evidence` і `plan_check.review` передається `pack.topic`.
4. Залишок (b) (власний термін вузла у вікні) і суд моделі (B) — не реалізовано: (b) потребує окремої перевірки пар «розділ — уривок» на записах (Astra), B — платного калібрувального проходу.

Не доведено: AI-відсотки нового файла; версійність копій (препринт ≠ стаття — локатори належать отриманій версії; перевірка ідентичності назви/авторів — у наступному кроці, якщо фаундер погодить).

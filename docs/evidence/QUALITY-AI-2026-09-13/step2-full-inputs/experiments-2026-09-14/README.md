## Як читати скани (правила визначені наперед)

- Порівнювати **розділ з розділом** у тому самому детекторі: A §1 42 %, §3 36 %, §5 27 %; B §1 48 %, §14 45 %. Сигнал — падіння на ≥ 20 пунктів або значення ≤ 15 % (Grok), і обидва повтори B в один бік (Astra). Один вдалий файл або розбіжні повтори = «зсув не доведений».
- Число файла — бонус, не єдиний критерій: якщо три розділи A сядуть у зону сусідів (0–13 %), файл орієнтовно ≈ 4–6 %; для B навіть ідеальні §1 і §14 лишають файл ≈ 14–15 % (решта рамкових розділів).
- Similarity B має впасти разом із часткою лапок у переписаних розділах; збереження 14 % при 0 лапок у §1/§14 означає, що збіги — в інших розділах.
- Формат файлів новий (пакет оформлення): типографіка змінилася для всього тексту; це не міняє сенсу порівняння розділів, але число файла з попереднім сканом порівнювати обережно.

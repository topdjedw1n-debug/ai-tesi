## У чому зійшлися

- **Простій — для першого живого замовлення, не для «дійти до 10/10 у коді».** Позначки доводять Compilatio на точному DOCX і прийняття змісту Танею; у простої без файла й людини їх не наздогнати.
- **Віддати економіку 3/3 редактору зараз** з італійським чеклістом — єдиний уже оплачений шанс дізнатися, чи «10/10 детектора» = прийнятий зміст (методологія з чужих методів, «кейси ПМІ» на Zooppa). Не чекати коду.
- **Лишити:** правові цитати (повна/однозначна назва акта, без подвійного «art.», «da verificare» лише як службова заглушка); видимий 429 Semantic Scholar (щоб `catalogue_unavailable` спрацьовував і порожній каталог ≠ «джерел немає»); попередження текстом на сторінці роботи Тані (message_uk + detail, без нових закликів «завантажте PDF»); **тонка** записка редактору лише з наявних сигналів (попередження прогону, fabrication_check, цитати без сторінки) — без нових детекторів фраз, довгих речень, «англійських цитат як помилки»; коротке оновлення канону.
- **Прибрати/відкласти:** загострення `plan_check` за дисципліною (нова евристика біля писаря; чесні мітки «є повний текст / є акт», придатність — «не встановлено»); підняття стелі $5 (лише рядок у каноні + оцінка, підняти під конкретне замовлення); інструмент сканів у репо (Astra — мінімальне перенесення, Grok — після першого замовлення); лабораторія з фіксованим пакетом; моніторинг/черга; другі ключі й кредити (спершу перевірити фактичне використання; Astra: у OpenAlex добовий бюджет зі скиданням опівночі UTC — «2,6 год» могло бути залишком); автоматизація деплою.
- **Зонд інформатики лише S2 (≈ $0,06)** — страховка поза цією сесією, окреме «так», якщо простій затягнеться і дисципліна першого замовлення невідома.
- **Режим першого замовлення — виправити обіцянки:** паузи після S2 в коді немає (S3 стартує одразу), тож «скасуємо за $0,10» — не гарантія; скасовувати лише порожній або явно чужий пакет; не скасовувати через `plan_material_gap`; Таня сама завантажує DOCX і приймає зміст; менеджер сканує; система перевіряє джерела; розробник усуває причину дефекту; будь-яке втручання розробника фіксується — такий цикл ще не доводить самостійності менеджера; 15/14 — рівень продовження, 10/10 — умова видачі; налаштування цитат у Compilatio зафіксувати до наступного приймального скану; замовлення важливіше за сесію — якщо приходить, сесію зупиняємо.

## Розбіжності (дрібні)

Записка редактору: Astra допускає DOCX через наявний експорт, Grok — текст/markdown без DOCX → **текст/markdown** (простіше, без нового конструктора). Канон: Astra — першим, Grok — після коду → в плані окремим пунктом, порядок не критичний. Інструмент сканів: Astra — мінімальне перенесення наявного скрипта, Grok — відкласти → **відкласти**, читаємо наявними скриптами. Астра додає **операційну репетицію без провайдерів** (статус → пояснення → скасування → завантаження → запис рішення; чи не стартує наступний етап після скасування) на наявних записах — включено як перевірку, не як нову лабораторію.

## Вердикти (збіглися в головному)

**Напрямок.** Обоє: зараз лагодити забезпечення джерелами (S2), а не писаря; варіація права B нічого не прибирає — право з PDF уже доходить до DOCX, а економіка без PDF написала чужу роботу, це ближче до «платформа не працює». Обоє **проти** моєї пропозиції B (реверт «своїми словами» + лабораторний скан B за $2,7 зараз): регресія тіла 7,8 → 18 % не доведена (одночасно змінилися речення, стеля 3 вікна, план 18→21, живий пакет, інший прогін детектора), а §9 «Ruoli» (AI 66 %, similarity 0) — це заборонений правилами плану розділ «role of», тобто **правила плану не вкусили**; similarity сидить у Гаранта/пошті/відео і «своїми словами» її не зняла. Обоє **проти** C як політики продукту (PDF обов'язкові для всіх дисциплін): перевірка джерел — обов'язок системи (канон, PF06); чесно — тимчасове повідомлення менеджерам «автопошук слабкий, якщо є PDF — завантажте». Обоє проти зв'язки двох змін (S2 + писар) в одній наступній трійці.

**Уточнення до читання результатів (Astra).** «Рамку вирішено» — передчасно: один скан, детектор ±10; порядок письма спрацював як механіка. Скан `.txt` не виконує вимогу перевірки точного DOCX. Розбіжність у зафіксованих критеріях: README consult4 каже «хвіст тіла ≥ 35 % на оглядових розділах», мій запит — «вступ/висновки ≥ 35 %». За передреєстрованим формулюванням **B кабінет — провал** (§9 66, §7 41, §4 40 %); за моїм — ні. Беремо передреєстроване; на рішення не впливає: продовжувати серію за 15/14 підстав немає.

**Технічні уточнення до фіксу S2.**
- Не шукати лише те, що не має власної літератури: вступ, висновки, бібліографія. Методологію, кейси, «evidenze empiriche», обговорення — шукати, але **з темою** (Grok: інакше наступна економіка впаде на «немає матеріалу в методах»; Astra: батьківський вузол не має прибирати предметні підвузли).
- Якір теми ставить S2 детерміновано (ядро теми з брифу + терміни вузла), не промпт S1 («Terms must name the actual subject» уже є і не спрацював). Голий `title` і голі структурні терміни не відправляти.
- Відсів кандидатів без жодного токена теми в title/abstract **до** верифікації (ріже і сміття, і зайві 429); відсутню анотацію не прирівнювати до нерелевантності (Astra). Прив'язка джерело↔розділ зараз іде від запиту, який його повернув, — виправити весь ланцюжок «запит → доречний кандидат → перевірене джерело → читабельний текст → уривок під питання розділу» (Astra).
- Каталоги лікувати за причиною, не «на око» (обоє). Зонди з сервера після консультації, по одному запиту: **Crossref** ввічливий пул з mailto відповідає `x-rate-limit-limit: 3` за 1 с і `x-concurrency-limit: 3` — наш лічильник 5 rps і 5–6 одночасних перевищує обидва; **OpenAlex** тепер має кредитний бюджет: `x-ratelimit-limit 1000`, один пошук коштує 10 кредитів, скидання через ≈ 2,6 год, prepaid 0 — тобто ≈ 100 пошуків на вікно безкоштовно, і S2 (≈ 160 запитів на роботу + верифікації) вичерпує його за одну роботу; звідси 274/274 × 429 у C. **Semantic Scholar** — 1 rps на всі endpoints з ключем; бюджет має бути спільним для пошуку, верифікації й повторів → 0,5 rps.
- Обмежені повтори з урахуванням `Retry-After`, спільна пауза для недоступного каталогу; «каталог недоступний» відрізняти від «джерел немає» (Astra). Пауза між роботами і ключ OpenAlex — лише після виміру (Grok), але кредитний бюджет OpenAlex робить ключ/ощадність (менше запитів на роботу) реальним питанням.

## Найменший достатній крок (обоє, без платного письма і без сканів)

1. **Викласти:** mailto у верифікаторі (34bcd10) + у середовищі сервера `CROSSREF_RATE_LIMIT_RPS=2`, `SEMANTIC_SCHOLAR_RATE_LIMIT_RPS=0.5`; одночасність до Crossref ≤ 3.
2. **Код S2 (`build_sources`, $0):** без вузлів вступу/висновків/бібліографії; запит = ядро теми + терміни вузла; відсів кандидатів без токена теми до верифікації; PDF менеджера не чіпати; менше запитів на роботу (OpenAlex-бюджет).
3. **Перевірка без генерації:** юніт на записаних деревах A (`A-doc21-events.json`) і C — 0 запитів для вступу/висновків/бібліографії, кожен інший містить токен теми, методологія не зникла, викликів помітно менше за 18×9; той самий відсів на зафіксованому списку кандидатів A («Copper complexes», «Tortura e razzismo», «Lessico», «Valutazione della ricerca» — геть; «PMI Marketing…», стаття про social/SMEs — лишаються); регресія на записаному пакеті B з 14 PDF (обов'язкові джерела й уривки не втрачено).
4. **Живий зонд** 8–10 запитів після викладу mailto: частка 429; якщо OpenAlex досі 100 % — ключ/ощадність.
5. Потім **одна економіка через кабінет** з гейтом «предметні розділи мають повний текст по темі»; скан лише за гейтом. Право не перезапускати. Писар — окремо, пізніше, на записаному пакеті B; безплатна дія зараз — прочитати завдання/уривки/позначені фрагменти §§4, 7, 9, 19 (Astra). Однорядкова зміна S4 «коротка цитата оперативних слів норми дозволена в чинному бюджеті» — допустима в тому ж викладі без лабораторного прогону (Grok), ефект міряти окремо.

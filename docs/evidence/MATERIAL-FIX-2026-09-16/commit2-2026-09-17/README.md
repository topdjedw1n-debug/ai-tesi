# Коміт 2 плану матеріалу (17.09.2026): звіти по матеріалу на чотирьох записах із кодом коміту

Той самий `scripts/material_report.py`, що для коміту 1: BEFORE = записані події, AFTER = поточний код (коміт 2: копії, рамка з комою, спільні слова іспиту без слів теми) на записаних сторінках. Копії тут не видно (звіт не ходить у мережу) — їх ефект показує [симуляція з завантаженими копіями](../copies-2026-09-17/psy-simulation.txt).

Що змінила правка «спільні слова без слів теми» проти коміту 1 (порівняння таблиць «Sections»):

- **PSY:** огляд про медиків у COVID більше не годує §8 FoMO (лишилися профільні анотації FoMO); дисертація про сексуальну освіту зникла зі вступу й дискусії; §16 висновки тепер рамка (без документів, з findings). Лишаються за own-термінами: медики у §12 «fattori protettivi» (supporto sociale, resilienza), сексуальна освіта у §13 «prevenzione a scuola», харчування у §14 (parental mediation) — це випадок для суду моделі.
- **E2:** §6 P2P втратив модель дефолту (не про P2P) і зберіг три профільні; §12/§13/§14 інші набори, жоден предметний розділ не лишився без документів.
- **A2, BIO:** зміни лише в порядку/складі допоміжних документів; жоден предметний розділ не втратив усі сторінки.
